# Binary-field Poseidon2b/Ligerito pilot

Evaluated a new coefficient-form GKR implementation of Poseidon2b with Flock GF(2^128) arithmetic and Ligerito against earlier BN254/WHIR and Flock Keccak hash proofs. This pilot used 72-byte logical inputs and varied hash checkpoint depth.

This is a historical experiment. Its source snapshots, raw trajectories, logs, binaries and backup bundles were removed; only this description and the selected small summaries or plots below remain. The three final experiments retain complete timing evidence and reproduction instructions in [the main README](../../../README.md) and [results/paper](../../../results/paper/README.md).
